# Accesibilidad

La interfaz está desarrollada con Win32. El proyecto busca compatibilidad con el uso del teclado, lectores de pantalla y escalado de Windows, pero **no ha completado una auditoría de accesibilidad**.

## Pendiente de verificar en Windows real

- Navegación completa por teclado y foco visible.
- Etiquetas accesibles, nombres y estados de controles.
- Alto contraste, escalado de texto y DPI.
- Relación entre ventana de bloqueo y tecnologías asistivas.
- Mensajes comprensibles cuando una URL no puede identificarse.

Para reportar barreras, abre una incidencia de mejora o error indicando versión de Windows, herramienta de asistencia utilizada y pasos, sin compartir información personal.
