# Código de conducta

Este proyecto busca una comunidad respetuosa e inclusiva para personas usuarias, mantenedoras y colaboradoras.

## Conducta esperada

- Tratar a todas las personas con respeto y empatía.
- Hacer críticas técnicas constructivas, centradas en el código y las ideas.
- Respetar la privacidad: no publicar capturas que revelen hábitos de navegación, identidades o datos personales.
- Aceptar diferencias de experiencia, idioma y perspectiva.

## Conducta inaceptable

- Acoso, ataques personales, amenazas o discriminación.
- Publicar información personal de otra persona sin autorización.
- Comentarios sexualizados no deseados, hostigamiento o sabotaje intencional.

## Cumplimiento

Las personas mantenedoras pueden editar, ocultar o cerrar aportes que vulneren estas reglas; ante reincidencias, podrán restringir la participación.

Para informar incidentes de conducta sin exposición pública, utiliza un medio privado de contacto ofrecido por las personas mantenedoras en sus perfiles de GitHub. Si no existe un canal privado disponible, usa las herramientas de denuncia de GitHub y evita publicar información sensible en Issues.

Se evaluarán los informes de forma confidencial en la medida de lo posible, con proporcionalidad y respeto a todas las partes.

Este es un código de conducta específico de FocoLocal Desktop, sin afiliación institucional.
