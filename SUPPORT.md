# Soporte

FocoLocal Desktop es software libre en etapa de evaluación y no ofrece soporte comercial ni tiempos garantizados de respuesta.

- **Instalación y funcionamiento:** consulta el [README](README.md).
- **Problemas reproducibles:** crea una incidencia con el formulario **Reportar un error**.
- **Compatibilidad Chrome/Edge/Firefox y otros:** usa **Compatibilidad de navegador** y adjunta versiones, no URLs privadas.
- **Propuestas:** abre **Sugerir una mejora**.
- **Seguridad:** usa únicamente el canal privado descrito en [SECURITY.md](SECURITY.md).
- **Pruebas manuales:** [docs/TESTING.md](docs/TESTING.md).

Si no se reconoce una URL, el programa puede no aplicar un límite. Consulta las limitaciones conocidas antes de depender de él para restricción estricta.
